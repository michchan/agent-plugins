# Phase 1 — Screening & Idea Generation

The top of the funnel. Start here when you don't have a specific name yet.

## Entry Points

These are different approaches — ask the user which to use before proceeding:

- **Top-down** (macro → sector → names): `equity-research:sector` — sector overview, then drill into names
- **Bottom-up** (criteria → names): `equity-research:screen` — screen with user's criteria
- **Event-driven** (catalyst → entry point): `equity-research:catalysts` — upcoming events across watchlist or sector

## Output
Save screening outputs to `/Equity-analyses/{Type}/Screening/`.

# Phase 5 — Ongoing Review

Once a position is open (folder moves to `/Holding/`), shift to monitoring cadence.

Ask the user which review type applies before proceeding:

- **Pre-Earnings**: `equity-research:earnings-preview`
- **Post-Earnings**: three steps in sequence — ask to run step by step or all at once:
  1. `equity-research:earnings` — beat/miss analysis, thesis check
  2. `equity-research:model-update` — update actuals, revise forward estimates
  3. `equity-research:thesis` — update or reaffirm
- **Between Earnings** (lightweight): two independent options — ask which to run:
  - `equity-research:morning-note` — macro + portfolio-level developments
  - `equity-research:catalysts` — upcoming events across full portfolio
- **Annual Review**: `equity-research:thesis` — reaffirm or close each position

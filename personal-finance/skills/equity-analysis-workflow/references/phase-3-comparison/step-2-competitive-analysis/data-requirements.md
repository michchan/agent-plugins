# Data Requirements — Phase 3 / Step 2: Competitive Analysis

Input fields needed to invoke `financial-analysis:competitive-analysis`.

| Field | Description | Example | Cache TTL |
|---|---|---|---|
| Subject business description | Segments, products, pricing model, customers | "Mid-market CRM SaaS, subscription model" | 1 year |
| Competitor descriptions | Business overview for each named competitor | "Salesforce: enterprise CRM, $34B revenue" | 1 year |
| Market share data | Estimated market share for subject and key competitors | "Subject: ~8%, Salesforce: ~22%, HubSpot: ~6%" | 1 year |
| Product / pricing differentiation | How subject's offering compares to competitors | "Lower price point, faster deployment vs. Salesforce" | 6 months |
| Moat indicators | Network effects, switching costs, cost advantages, IP | "High switching costs: deep CRM integrations" | 1 year |
| Recent competitive events | New entrants, competitor product launches, M&A | "HubSpot launched AI CRM feature in Q1 2025" | 1 month |
| Step 1 comps output | Relative valuation context | _(from current session)_ | Current session |
| Phase 2 competitive context | Step 1b output if run | _(from current session or saved)_ | Current session |
